# USB、坐标映射与 V2 自然跟随

## 连接

从 DK 根目录运行 `bash "VR remote control/start-bridge.sh"`，或使用 RS 的“RD数据桥配置”。单独使用时先在本模块创建环境并安装 requirements.txt。连接 Quest、允许 USB 调试并在 RS 一键同步；脚本默认自动选择唯一已授权 USB 设备，多个设备需指定 QUEST_SERIAL。

USB 的数据端口通过 `adb reverse tcp:8766 tcp:8766` 转发；监视页为 http://127.0.0.1:8767 。拔插后需重新配置转发；桥已运行时无需重复启动。

## 现有 V2 行为

固定操作位置与朝向，第一次握住建立手柄与机械臂 TCP 的相对起点。Unity 前／左／上对应机器人 +X／+Y／+Z，三轴统一 positionGain，默认 1∶1。位移目标每轴范围 ±0.6 m，映射限速 0.4 m/s；这些范围不保证机械臂实际可达。锚点距离超过 0.8 m 被视为异常。

姿态相对握持时的朝向跟随，无每次握持 45° 限幅；姿态目标限速 90°/s，单次采样跳变超过 100° 会拒绝。旋转使用 M R Mᵀ，不能把平移轴直接套在四元数向量上。姿态开关默认勾选。

松开右握键保持，再握住重新建立起点；追踪失效需要松开后重新启用。触发开关开启时，扳机相对变化控制夹爪，避免初次握住时突然全开／全闭。A 启动／重置跟随，B 返回抓取位姿。

仿真链路与真机执行限速并不相同；真机另受 DK 关节速度、反馈、偏差、路径与会话保护。具体条件见 [hardware-control.md](hardware-control.md)。射线与界面交互会影响连续跟随，见当前真机控制说明。
