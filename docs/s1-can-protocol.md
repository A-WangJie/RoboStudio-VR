# 本机 S1 V1 状态与电机模式指令核对

2026-11-16，适配当前设备及 `S1_SDK_V2/src/S1_SDK/hardware/motor_interface.cpython-310-x86_64-linux-gnu.so`。

生产实现不创建 S1ARM / Middle_Ware，因为其构造、后台线程与析构包含模式初始化、失能及关闭行为。状态和使能页面使用下表三个操作；新增的显式鼠标真机通道见文末，不开放通用 CAN 帧写入。

| 操作 | 标准 CAN ID | DLC | 八字节数据 |
| --- | --- | --- | --- |
| 状态查询 | 0x7ff | 8 | node低字节、00、cc、00、00、00、00、00 |
| 使能 | node | 8 | ff ff ff ff ff ff ff fc |
| 失能 | node | 8 | ff ff ff ff ff ff ff fd |

节点 1–6 为关节，平行夹爪配置加入节点 7，无末端配置不发送节点 7。查询读取不需要先使能。

连接探测读取 `0x0a` 控制模式寄存器：查询数据 `node 00 33 0a 00 00 00 00`，回复头为 `node 00 33 0a`，后四字节是小端模式值，**不是固定为 1 的成功标志**。本机已验证模式 1 和 2；鼠标／VR 位置速度通道使用模式 2。2026-11-16 实测六关节回复 `02 00 00 00`、夹爪回复 `01 00 00 00`，均应计为在线。旧检测曾只接受模式 1，导致切换控制模式后误报关节缺失；现已修正并加入混合模式回归测试。探测不写入或重置控制模式。

核对来源：本机二进制导出函数 `damiao::refresh_motor_status()`（0x5d180）、`damiao::enable()`（0x5cc40）、`damiao::disable()`（0x5cce0）、`damiao::process(frame_data)`（0x5cdf0）、`damiao::damiao()`（0x5d510）以及 `can::recv()`（0x58d60）。`tests/test_hardware_operations.py` 在无任何传输对象的条件下构造纯 damiao 值对象，比较原生函数生成的帧和解析结果。

回复实机 ID 为 0x11–0x17，DLC 8。拒绝扩展、RTR、错误帧、未匹配节点、ping 回复和本机回环。SocketCAN 过滤掩码用 `CAN_SFF_MASK | CAN_EFF_FLAG | CAN_RTR_FLAG`，不能用包含 CAN_ERR_FLAG 的全位掩码，否则会转入错误帧订阅路径，收不到正常回复。

反馈数据 d0…d7：

- 节点：d0 低四位，必须与回复 ID 对应；状态：d0 高四位。0 失能、1 使能，8–14 为故障码。保留故障，不把故障当失能成功。
- 位置：`((d1 << 8) | d2) × 25 / 65535 − 12.5` rad；第七节点按 SDK 反号。
- 速度：`((d3 << 4) | (d4 >> 4)) × (2 × vmax) / 4095 − vmax` rad/s。
- 力矩：`(((d4 & 15) << 8) | d5) × (2 × tmax) / 4095 − tmax` N·m。
- 节点 1–3：vmax = 8，tmax = 28；节点 4–7：vmax = 30，tmax = 10；均从本机 SDK 节点表取得。
- d6 为 MOS 温度，d7 为线圈温度，单位 ℃。

查询前丢弃旧队列，按节点依次发出查询，每节点至少间隔 20 ms；仅接受发出该节点查询后的反馈。读取不改模式，不发送位置／力矩目标，不写零位。角度超出约 ±π 标记异常，禁止据此使能；这与具体机械限位／标定是不同检查。

使能前必须有同目标、同配置的 10 秒内完整读取，并再次复查反馈。发送后重新查询确认；无回复或反馈不符时显示未完全确认。失能不以先前完整读取为条件，尽量覆盖所有配置节点。

实机验证只执行状态查询：七个节点成功返回，状态码均为 0。使能／失能通过模拟设备和原生生成帧对照验证，本次没有对真机执行这两项操作。

## 鼠标通道新增指令

- `damiao::control_pos_vel(float,float)`（0x5cb80）：标准 ID `0x100 + node`，DLC 8，两个小端 float 为位置 rad、速度上限 rad/s。节点 7 的 SDK 位置取反，速度参数不取反。
- `damiao::switchmode(2)`（0x5d460）：标准 ID 0x7ff，八字节 `node 00 55 0a 02 00 00 00`。只在显式真机会话收到首个有效鼠标运动目标后使用。
- `tests/test_hardware_mouse.py` 对节点 1–7 使用纯内存 damiao 值对象，逐字节对照原生生成帧，未创建传输对象。高层 `Middle_Ware::control_gripper_pos_vel`（0x56100）也确认夹爪位置反号。

工作流、反馈监控与现场验证边界见 [mouse-hardware-control.md](mouse-hardware-control.md)。
