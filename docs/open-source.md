## 验证限制

官方参考提交尚未完成全新机器的原生构建验证；临时 SDK 包只验证本项目扩展，不验证官方 S1_arm 导入链和编译依赖。
自动检查跳过未分发的本机终端脚本改动、缺少原生 SDK 的对照项及需要显式开启的浏览器和桌面图形检查。
源码中未发现所检查格式的 GitHub 令牌、私钥块或本机 Quest 序列号；此有限扫描不构成所有敏感信息均不存在的保证。
官方 pyproject 声明 MIT，但无独立许可证与模型授权说明；模型再分发仍待确认。
