# 机械臂控制与当前项目导航

工具栏顺序为“机械臂配置 → 机械臂控制 → 数据采集”。“机械臂控制”合并原有从臂示教、鼠标控制、AR / VR 入口，三级菜单如下：

```text
机械臂控制
├─ 从臂示教
│  ├─ 单 / 双臂主从示教
│  ├─ 主从配对与设备
│  ├─ 关节映射与对齐
│  └─ 示教操作说明
├─ 鼠标控制
│  ├─ 关节控制（含夹爪）
│  └─ 末端位姿 / 三维拖拽（含长跟随）
└─ AR / VR
   ├─ 设备与采集
   ├─ 遥控操作
   ├─ 手柄实时数据
   └─ 使用说明
```

点击二级分类或箭头展开 / 收起第三层；点击具体功能打开右侧已有页面。菜单支持上下方向键、右方向键展开、左方向键收起、Esc 关闭；点击外部也会关闭。所有控件、参数和命令接口继续复用原有实现，菜单展开和页面切换不会启动示教、VR 或机械臂运动。

项目树在 S1 Base 下增加当前工作区文件节点。未保存时显示 `RoboDK（未保存）`；桌面版打开、保存、另存或新建后同步文件名和真实路径。悬停文件节点或单击打开项目与模型信息页，可查看路径和当前页面关系。

文件节点下列出工具栏同一份功能目录，支持点击叶节点或按 Enter 跳转。切换页面会展开对应祖先节点，以浅蓝色标记当前页面；深蓝色仍表示树中选中的对象。原有机器人、六关节、夹爪、TCP、目标和工作平面节点继续保留。

这里的目录是当前项目的功能导航，不是磁盘文件扫描或新增的机械臂程序。工作区文件格式保持不变，主从配对页在配置分类和示教分类中仍共享同一份参数。

## 快捷目标栏显示管理

右键项目树中的功能文件夹或具体功能，选择“移出快捷目标栏（项目树）”可隐藏入口。右键工具栏对应的功能图标，或展开菜单后的二级分类 / 第三级功能，可选择“添加到快捷目标栏（项目树）”恢复入口，也可直接移出。显示选择只影响项目树；功能页面、输入参数和工具栏入口继续保留。

移出父目录会同时隐藏其子项。添加某个子功能时会恢复必要的父目录，但保留其他子功能各自的隐藏选择。访问已移出的功能不会自动将它加回项目树。机械臂本体、关节、TCP 等场景对象保留原有展示和操作。

菜单支持右键、键盘菜单键或 Shift+F10；Esc 关闭并恢复焦点，点击外部关闭。添加 / 移出不会发送机械臂运动命令。

桌面版将选择自动保存到 `.local/config/project-shortcuts.json`，重启时恢复，不受本地仿真服务端口变化影响；网页版保存在当前站点的浏览器本地存储中。此项是工作台显示偏好，不更改 `.s1studio` 工作区文件格式。首次使用保留原有目录，由用户按需移出。

实现位于 `app/js/project-shortcuts.js`。Chrome 验证记录为 `shortcuts-checks.json`，桌面联动及配置恢复记录合并在 `navigation-desktop-checks.json`；预览为 `project-shortcuts.png` 和 `project-shortcuts-desktop.png`。

目录定义位于 `app/js/navigation.js`，多级菜单位于 `app/js/function-menu.js`。联动验证使用 Google Chrome 和隔离的 Electron / MuJoCo 环境，分别运行 `tests/test_navigation_chrome.py`、`tests/test_navigation_desktop.py`。截图见 `navigation-menu.png`、`navigation-desktop-menu.png`、`navigation-project.png`；检查结果见 `navigation-checks.json` 和 `navigation-desktop-checks.json`。


工程整理后，本文提到的检查 JSON 统一位于 `artifacts/reports/`，生成截图位于 `artifacts/screenshots/`；这些本机材料不随源码导出。当前路径与配置以 [配置说明](configuration.md) 为准。
