# 从臂示教模块

工具栏入口为“机械臂控制 → 从臂示教”，展开箭头后选择单 / 双臂示教、主从配对、关节映射或说明页面。项目树中当前项目下的同名目录也可直接跳转。按实体主臂方案准备：手动拖动主臂，读取六关节角度与夹爪，再驱动配对的从臂。

当前提供共享配置、格式校验与离线角度预览。实体主臂读取、从臂运动、重力补偿和实体示教轨迹采集尚未接入，启动与停止示教按钮保持禁用，不会伪造运行状态。现有 VR 数据采集保持原有用途。

## 页面

- 单 / 双臂主从示教：数量、配对概览、目标频率、输入超时和夹爪跟随。
- 主从配对与设备：也可从“机械臂配置 → 主从示教配置”打开。A、B 为从臂；各自主臂有独立接口、速率和名称。
- 关节映射与对齐：逐轴方向、比例与偏移，人工对齐记录及离线角度预览。
- 示教操作说明：设备准备与操作顺序。

单臂为一组主从，双臂为两组主从。切换单臂保留 B 组配置。自动识别选项仍为后续策略，当前不探测设备。

## 共享配置

桌面版沿用 `.local/config/arms.json`，网页调试沿用浏览器本地存储 `robostudio.arm-config.v1`。两者的存储介质不同；同一运行实例内，机械臂配置页与示教页共用一份编辑草稿和保存操作。

`connection.layout` 决定从臂数量，`arms[0/1]` 保存从臂参数，新增 `teaching` 保存频率、超时、夹爪跟随和 `pairs[0/1]`。每组含主臂名称 / CAN 接口 / 速率，以及六轴 `direction`、`scale`、`offsetDegrees` 与人工对齐记录。主臂接口默认未分配，避免猜测硬件绑定；保存时检查参与通道与从臂的接口冲突。

旧版配置读取时自动补充示教默认值，不改动既有从臂和 VR 参数。只有点击保存才写文件。所有字段为配置，不改变 CAN 接口、不加载 SDK、不启动机器人。

## 映射

`q_target[j] = q_leader[j] × direction[j] × scale[j] + offsetDegrees[j]`

角度单位 °。同构主从可从方向 +1、比例 1 开始核对；若要匹配各自起始角，可根据 `offset = q_follower_start − q_leader_start × direction × scale` 准备偏移，再现场核对。此版本不会自动读取或标定起点。

离线预览只计算目标，逐关节报告是否超出当前 S1 V1 配置限位，不裁剪角度、不执行运动，也不表示已完成碰撞或路径验证。

后续接入实体主从服务时，应使用真实设备状态、输入时间戳和人工使能决定是否允许启动，并实现断线 / 超时停止、姿态对齐、限位 / 路径检查及专用示教录制。当前 UI 的“参与示教”只保存通道选择，不是运行开关。
