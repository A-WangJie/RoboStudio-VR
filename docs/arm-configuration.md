# 机械臂真机配置与连接检测

新增的鼠标真机通道位于“机械臂控制 → 鼠标控制”页面顶部。使用方式及与仿真的区别见 [鼠标控制 S1 V1 真机](mouse-hardware-control.md)。初始化页面的状态读取、使能、失能仍独立操作；真机复位与抓取位姿通过鼠标／VR 的受限运动会话执行，参数页保存不自动运动。

入口：最左侧文件工具组，保存图标旁的 **机械臂配置 ▾**。选择子项后在右侧侧栏展开；侧栏收起后也可从此入口重新打开。

## 页面

- **连接与设备识别**：显示系统 CAN 接口的启停、实际速率、总线状态与收发错误；“检测机械臂”查询已配置 A / B 上的节点响应。单臂仅检测 A；自动与双臂分别检测 A、B 并统计完整响应的机械臂，不自动改绑接口。
- **机械臂参数**：A / B 名称、SocketCAN 接口、CAN bitrate、平行夹爪或无末端、未来控制服务的自碰撞检查策略。可查看各槽位的节点响应，并将接口实际速率填入草稿；需点击保存，不会更改系统 CAN 设置。
- **初始化与复位**：读取状态和限位核对策略、人工使能、六关节复位目标、复位速度规划。“检查接口与响应”可用；“复位参数检查”验证配置目标和范围，并提示节点检测是否新鲜。已接入手动读取实际关节和夹爪状态、使能、失能；选择 A 或 B 后只操作选定机械臂。复位使用鼠标控制页的姿态按钮，并受当前会话条件限制。
- **AR / VR → 输入配对与坐标**（已移至独立工具栏入口）：独立执行臂与左右手输入的分配、位移比例、共同工作坐标系中的基座位姿、法兰坐标系中的 TCP 平移偏移、人工标定记录、按住使能和输入超时。当前仅保存配置，不运行 AR 跟随。姿态按 Rz(Yaw) · Ry(Pitch) · Rx(Roll) 解释，均为配置约定，等待未来设备适配验证。

A / B 不表示主从、示教关系或物理左右；CAN 编号也不作为位置识别依据。AR 双臂不能同时绑定同一个手部输入。

## 保存与边界

桌面版首次读取缺省配置不会写文件。点击“保存配置”后写入项目 `.local/config/arms.json`，使用独立于 MuJoCo 设置与 `.s1studio` 位姿文件的配置存储。保存只验证并原子写入 JSON。单臂模式保留 B 的设置。未设置速率、复位目标、AR 分配或坐标标定可以保存草稿，并显示待办事项。

“校验配置”仅校验格式、范围、重复 CAN 接口与重复 AR 输入，不证明设备连接、SDK 安装、标定正确、路径可达或运动安全。损坏的现有配置会显示读取失败，不会被默认配置静默覆盖。浏览器调试版使用该站点的 localStorage，与桌面配置文件不互通。

## 检测与状态含义

检测只向配置接口发送已与 S1 V1 SDK `search_arm` 实际行为核对过的 ping 查询，不构建 S1_arm，也不发送使能、失能、运动或零位写入。标准 CAN ID 为 `0x7ff`，八字节数据为节点编号（小端两字节）、`33 0a 00 00 00 00`。节点 1–6 为关节，选择平行夹爪时还需节点 7。仅计入对应 ID、完整成功标记的外部响应，排除本机回环。

接口不存在、未启动、总线 BUS-OFF 或配置速率不一致时不发送探测，直接显示原因。节点缺失显示具体编号；空闲总线上没有主动反馈不能作为断线依据。服务仅检测配置的接口，不扫描任意总线或自动启动接口。

连接、设备参数、初始化页面共享检测结果；从任何一页点击检测，进度、节点响应数与失败原因均在当前页就地显示。初始化页另行提供真机目标选择、状态表和使能／失能反馈。

检测结果是一次响应快照，不是持续在线、实际关节状态或运动许可。超过 10 秒标记为历史结果；更改检测参数、接口状态改变或接口读取失败后旧结果失效。复位参数检查不替代实际起点、限位、标定和路径检查。

已保存配置开启“自动检测”时，每次软件启动后第一次进入真机配置页检测一次。无保存配置时不自动探测；保存参数本身不探测。后续更改参数或重连需点击重新检测。显示页面时每三秒只读刷新接口信息。多个 RS 检测任务通过文件锁互斥，检测不会使机械臂运动，也不改变仿真姿态。

桌面配置文件：`.local/config/arms.json`。2026-11-16 当前设备已配置为单臂 A / can0 / 1000000 bit/s / 平行夹爪；B 设置保留。实机验证七个节点全部响应，收发错误均为零；记录在 `artifacts/reports/hardware-diagnostic-20261116.json`。复位姿态和标定仍未设置，不直接套用仿真姿态。

## 手动读取、使能与失能

入口：**机械臂配置 → 初始化与复位**，选择“真机操作目标”A / B。单臂模式只允许 A。

- **读取状态**：显式发送独立状态查询，返回 J1–J6 与配置夹爪的角度、使能状态、速度、力矩、MOS 与线圈温度。每节点需本次新回复，丢弃查询前排队的旧帧和本机回环。缺失节点不填零，也不认为在线。
- **使能电机**：先读取完整状态，勾选现场确认后，在 10 秒内点击。后端再次读取，检查节点完整、无故障、角度有效，再仅向尚未使能的节点发送使能指令，随后读回状态。发送成功不等于执行成功；反馈不全、未改变或通信中断均不会显示全部成功。
- **失能电机**：不依赖先前读取或使能确认；向目标配置内所有节点尝试失能，即使某节点发送失败也继续其余节点，再读回确认。失能撤去电机支撑，请先托稳机械臂。此按钮依赖电脑、总线与电源，不是硬件急停。

读数仅为快照，超过 10 秒标为历史；参数或目标改变后旧读数不可用于使能。显示夹爪 SDK 电机角度，与仿真开合百分比不是同一量，尚未做行程标定。解析范围与符号采用本机 S1 SDK（第七节点位置反号），不以仿真当前姿态替代实际状态。

保存配置、打开页面、自动检测、VR 跟随及关闭 RS 均不发送使能／失能。关闭软件不会自动失能，也不改变原有电机状态。三个按钮不下发目标位置、速度、力矩、重力补偿或零位写入，尚未接入真机运动／复位和仿真同步。使能会让电机输出力矩；本次开发只执行了真机读取，未实际使能或失能。

单次状态查询最多 2 秒；使能包含前后两次查询。检测、读取与模式命令共用多实例文件锁。操作日志在 `.local/audit/hardware-operations.jsonl`，记录命令与反馈是否确认；通信异常时记录结果未知。当前真机读数记录在 `artifacts/reports/hardware-state-20261116.json`。

HTTP：`POST /api/hardware/read|enable|disable`，只接受工作台同源 JSON。请求包含检测配置 `config`、目标 `armId`；使能还必须有显式 `confirmed: true`。不会在后台自动重试使能。

- `doc/S1_V1本地适配说明.md`、`examples/python/common.py`：S1 V1 使用 Linux SocketCAN；can0 / can1 为常见接口名；不能仅凭接口存在或 UP 判断机械臂在线。
- `examples/python/check_arm.py`、`src/S1_SDK/S1_arm.py`：Arm_Search 会探测总线，S1_arm 初始化可构建真实电机接口，生产检测不调用 SDK 构造器或 Arm_Search；仅复用已核对的 ping 协议。

- `examples/python/set_zero_position.py`、`S1_arm.set_zero_position` / `set_end_zero_position`：写入当前位置为零，不等于运动复位，因此未作为复位按钮的实现。

## 代码与验证

- `app/js/arm-config-model.js`：前端与桌面共用默认值、严格验证和未完成配置提示。
- `app/js/arm-config.js`、`app/arm-config.css`：共享参数编辑、保存及撤销未保存修改。
- `backend/hardware.py`、`server.py`：接口只读检查、受同源限制的显式节点探测和多实例互斥。
- `backend/s1_can.py`、`backend/hardware_operations.py`：独立状态查询、使能／失能、反馈核验和操作日志。
- `app/js/hardware-operations.js`：目标选择、状态表、现场确认与按钮状态。
- `app/js/hardware-diagnostics.js`：检测界面、结果失效、实际速率采用和复位参数检查。
- `desktop/arm-config.cjs`：固定配置路径的 JSON 读取与原子保存，不执行设备操作。
- `tests/arm-config.test.cjs`：持久化、错误配置拒绝、旧文件保护。
- `desktop/smoke.cjs`：真实 Electron 中验证入口、单/双臂切换、重复接口拒绝、保存、AR 分配、撤销、使能前置条件、禁用运动复位及仿真命令计数不变。

- `tests/test_hardware.py`：参数、协议帧、回环过滤、超时、接口状态、互斥和 HTTP 请求约束；使用模拟传输，不访问真机。
- `tests/test_hardware_chrome.py`、`tests/browser-hardware.js`：真实 Google Chrome 中验证检测、失效、采用速率、单/双臂、失败重试、保存和一次自动检测；使用模拟检测服务，不访问真机。

- `tests/test_hardware_operations.py`：SDK 离线帧／解析对照、只读查询、使能前置条件、失能、异常反馈和日志；除显式单独真机读取验证之外，自动测试不访问 CAN。

修改后端或桌面存储桥接后需要完整关闭并重新启动应用。
